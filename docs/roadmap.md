# Roadmap

Phases, not dates. Each phase is done when its exit check passes.

## Phase 0: the public readout (this repository)

- Static site with the brand, live block, TVL and pair board.
- Contract, X and GitHub slots that stay inert until stated. X is stated; contract and GitHub are not.
- Thirty automated gates covering both states of every slot.

Exit check: build and gates exit 0, with both branches of every slot proven.

## Phase 1: the persona builder

- Turn a short pitch into an identity: face, voice, temperament.
- Keep the identity steady across everything the persona produces.
- Label every persona as an AI character.

Exit check: the same pitch twice gives personas that feel like two separate characters, and one persona stays recognisable across its content.

## Phase 2: presence and content

- Generate media for a persona: images, clips, posts.
- Give each persona a home where its community can gather.
- Add review and reporting so unsafe content can be pulled.

Exit check: a persona can publish for a week without hand editing, and every item can be traced to the persona that made it.

## Phase 3: the coin

- Specify how a persona's coin is created, priced and split between creator, community and platform.
- Implement the contracts with a test suite on a local chain.
- Independent review of the contracts, with the report published.

Exit check: the specification is public, tests pass, and every review finding is closed or explained.

## Phase 4: launch on Robinhood Chain

- Deploy, verify the source, and publish the address.
- Flip the contract record to stated; the slot at the top of the site becomes live.
- Link GitHub once the repository is public.

Exit check: the address on the site matches the verified deployment.

## Phase 5: community steering

- Give holders a defined, limited way to influence where a persona goes next.
- Publish how influence is counted and capped.

Exit check: a holder can see how their stake affected a decision.

## Not planned

- Anything that needs the platform to hold user keys.
- Personas that give financial advice or promise returns.
- Impersonating real people.
